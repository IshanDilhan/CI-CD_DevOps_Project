# Application provenance

This lab adapts the existing React / Express / PostgreSQL todo application and
infrastructure from https://github.com/emir-ertan/CI-CD-Pipeline-For-Full-Stack-Application.
The imported Git commit is `76111d55f3dc31808b72d9403fbcc5a4248f5c9c`, authored by
Emir Ertan. The application is not claimed as original portfolio-author work.
The original UI included Cloud&Cloud branding; its asset is retained in source.

The DevOps lab changes add local orchestration, CI stages, tests, health checks,
versioned deployment, and operational documentation around that application.
The frontend was originally bootstrapped with Create React App.
